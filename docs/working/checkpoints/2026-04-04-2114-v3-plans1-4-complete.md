- **Save metadata** — new skills need auto-publish before bump; SKILL.md needs frontmatter; plugin vs skill layout detection
- **Hardcoded URL** — search chunks had `<worker>` placeholder; model hit wrong endpoint
- **MCP instructions invisible** — Claude.ai doesn't surface server `instructions` field; model only sees tool descriptions
